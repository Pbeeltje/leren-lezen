# Leren Lezen

Speelse web-app voor kinderen van 3 tot 6: leren lezen (Veilig Leren Lezen, maan-versie),
tellen en rekenen, luisteren en kleuterspelletjes. Vite + TypeScript + three.js, geen backend.

- Online: https://pbeeltje.github.io/leren-lezen/
- Lokaal: `npm install`, dan `npm run dev`
- Elke push naar `main` wordt automatisch gebouwd en gepubliceerd (`.github/workflows/deploy.yml`).

Bronbestanden (werkbladen, ruwe opnames) staan alleen lokaal in `bronbestanden/` en horen niet
in deze repo; alleen de uitgesneden plaatjes en geknipte geluiden in `public/` worden gepubliceerd.
